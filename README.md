# Obsidian Vault

A personal knowledge base and note-taking vault for use with [Obsidian](https://obsidian.md/).

## What is This?

This repository contains a pre-configured Obsidian vault with a sensible folder structure and default settings. It's ready to use out of the box for personal note-taking, knowledge management, and second brain workflows.

## Features

- **Pre-configured settings**: Includes sensible defaults for Obsidian
- **Organized folder structure**:
  - `Notes/`: General notes and documents
  - `Templates/`: Note templates for consistent formatting
  - `Attachments/`: Images and other file attachments
- **Essential core plugins enabled**: File explorer, search, graph view, backlinks, templates, and more
- **Sample templates**: Daily notes and meeting notes templates included
- **Welcome guide**: Get started quickly with the included welcome note

## Getting Started

### Prerequisites

Download and install [Obsidian](https://obsidian.md/) for your platform (Windows, macOS, or Linux).

### Using This Vault

1. **Clone this repository**:
   ```bash
   git clone https://github.com/jconwell3115/obsidian_vault.git
   ```

2. **Open in Obsidian**:
   - Launch Obsidian
   - Click "Open folder as vault"
   - Select the cloned `obsidian_vault` folder

3. **Start taking notes**:
   - The Welcome.md file will open automatically with more information
   - Create your first note in the `Notes/` folder
   - Use templates from the `Templates/` folder for consistent formatting

## Folder Structure

```
obsidian_vault/
├── .obsidian/          # Obsidian configuration files
├── Notes/              # Your general notes
├── Templates/          # Note templates
├── Attachments/        # Images and other attachments
├── Welcome.md          # Getting started guide
└── README.md           # This file
```

## Tips

- Use `[[Note Name]]` to create links between notes
- Add `#tags` to organize and find notes easily
- Press `Ctrl/Cmd + P` to open the command palette
- Explore the graph view to visualize connections between notes
- Customize settings via Settings → Options
