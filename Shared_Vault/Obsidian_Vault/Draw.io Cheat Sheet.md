# 🧠 **Draw.io (diagrams.net) Cheat Sheet**

---

## 🔹 **Getting Started**

| Feature | Description | |--------|-------------| | **Website** | https://draw.io or https://app.diagrams.net | | **Storage Options** | Google Drive, OneDrive, Dropbox, GitHub, Device | | **File Format** | `.drawio`, `.xml`, `.png` (with embedded XML), `.svg` | | **Offline Mode** | Available via desktop app (Windows, macOS, Linux) |

---

## 🧰 **Basic Tools**

| Tool | Shortcut | Description | |------|----------|-------------| | **Select Tool** | `Esc` | Select and move objects | | **Rectangle** | `R` | Draw rectangles | | **Ellipse** | `O` | Draw circles/ellipses | | **Line/Arrow** | `L` | Draw connectors | | **Text** | `T` | Add text boxes | | **Undo/Redo** | `Ctrl+Z / Ctrl+Y` | Undo or redo actions | | **Zoom In/Out** | `Ctrl + / Ctrl -` | Zoom canvas | | **Fit to Screen** | `Ctrl+Shift+H` | Fit diagram to screen |

---

## 🧱 **Shapes & Layout**

| Feature | Description | |---------|-------------| | **Shape Library** | Access via left sidebar (Flowchart, UML, ERD, BPMN, etc.) | | **Drag & Drop** | Drag shapes from sidebar to canvas | | **Resize** | Use corner handles | | **Rotate** | Use rotate handle or `Alt + drag` | | **Group/Ungroup** | `Ctrl+G / Ctrl+Shift+U` | | **Align** | Use toolbar or right-click → Arrange | | **Distribute** | Evenly space elements horizontally/vertically |

---

## 🔗 **Connectors & Lines**

| Feature | Description | |---------|-------------| | **Connector Types** | Straight, Elbow, Curved | | **Change Connector Style** | Right-click → Format → Line | | **Arrowheads** | Customize start/end arrows | | **Snap to Shape** | Auto-connect to shape edges | | **Floating Connectors** | Connect anywhere on shape | | **Fixed Connectors** | Connect to specific points |

---

## 🎨 **Styling & Formatting**

| Feature | Description | |---------|-------------| | **Fill Color** | Format panel → Style → Fill | | **Border Color** | Format panel → Style → Line | | **Text Styling** | Bold, Italic, Font, Size, Color | | **Shadow** | Enable in Style tab | | **Opacity** | Adjust transparency | | **Rounded Corners** | Set corner radius for rectangles |

---

## 🧩 **Advanced Features**

| Feature | Description | |---------|-------------| | **Layers** | View → Layers → Add/manage layers | | **Templates** | File → New → Choose from templates | | **Custom Libraries** | File → New Library or import `.xml` | | **Insert Images** | Arrange → Insert → Image | | **Embed Diagrams** | Export as HTML or SVG with embedded data | | **Version History** | Available when using cloud storage | | **Keyboard Shortcuts** | Help → Keyboard Shortcuts |

---

## 📤 **Export & Sharing**

| Format | Description | |--------|-------------| | **PNG** | With or without embedded XML | | **JPEG** | For simple image export | | **SVG** | Scalable vector format | | **PDF** | High-quality print-ready | | **HTML** | Interactive diagrams | | **Embed in Docs** | Use iframe or image link | | **Publish to Web** | File → Publish Link |

---

## 🧠 **Tips & Tricks**

- ✅ **Use Grids & Guides**: View → Grid or Guides for alignment
- 🔁 **Auto Layout**: Arrange → Layout → Choose layout type
- 🧮 **Math Support**: Insert LaTeX via `Insert → Advanced → Math`
- 🔍 **Find & Replace**: `Ctrl+F` to search text in diagram
- 🧱 **Reusable Components**: Create custom shapes and save to libraries
- 🧭 **Navigation**: Use mini-map for large diagrams
