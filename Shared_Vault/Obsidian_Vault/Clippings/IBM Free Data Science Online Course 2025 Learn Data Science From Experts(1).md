## Related Terms

**Python:** The one universal language of data sciences. It is loved because it is as simple as writing English.

## Common Mistakes Beginners Tend to Make in Data Science

Even the world’s best learners have been known to stumble. Here are a few pitfalls that beginners should avoid:

- Jumping into ML without mastering basics. Get Python and statistics right first.
- Ignoring data cleaning. 80% of a data scientist’s time is spent cleaning. Don’t skip it.
- Overfitting models. Don’t make your model memorize; make it generalize.
- Not practicing. Data readings alone will not make one a data scientist; building projects will.

## Mini Projects to Experiment On During the Journey

1. ### Movie Recommendation System

#### What You Will Learn

- Basics of similarity scores
- Using Pandas to build a simple recommender

Python Code Example

import pandas as pd

from sklearn.metrics.pairwise import cosine\_similarity

from sklearn.feature\_extraction.text import CountVectorizer

\# Sample dataset

movies = pd.DataFrame({

‘Title’: \[‘Inception’, ‘Interstellar’, ‘The Dark Knight’, ‘The Prestige’, ‘Memento’\],

‘Genre’: \[‘Sci-Fi Thriller’, ‘Sci-Fi Drama’, ‘Action’, ‘Mystery Thriller’, ‘Thriller Mystery’\]

})

\# Convert genres into vectors

vectorizer = CountVectorizer()

genre\_matrix = vectorizer.fit\_transform(movies\[‘Genre’\])

\# Compute similarity

cosine\_sim = cosine\_similarity(genre\_matrix)

\# Recommend movies similar to Inception

similar\_movies = list(enumerate(cosine\_sim\[0\]))

similar\_movies = sorted(similar\_movies, key=lambda x: x\[1\], reverse=True)

print(“Movies similar to Inception:”)

for i in similar\_movies\[1:\]:

print(movies\[‘Title’\]\[i\[0\]\])

‘Price’: \[100000,150000,200000,250000,300000\]}

\# Features and target

X = df\[\[‘Area’\]\]

\# Train model

\# Predict price for 2200 sq ft

- A minimal data analysis using Pandas

\# Sample dataset

data = {‘Student’: \[‘Amit’, ‘riya’, ‘john’, ‘sara’\],

‘Math’: \[85, 92, 78, 88\],

‘Science’: \[80, 95, 70, 90\]}
