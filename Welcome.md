# Welcome to Your Obsidian Vault

This is your personal knowledge base. Start taking notes and organizing your thoughts!

## Getting Started

### What is Obsidian?
Obsidian is a powerful knowledge base that works on top of a local folder of plain text Markdown files.

### Folder Structure
- **Notes/**: Store your general notes here
- **Templates/**: Keep note templates for consistent formatting
- **Attachments/**: Store images and other files

### Basic Features
- Create links between notes using `[[Note Name]]`
- Add tags using `#tag-name`
- Use Markdown formatting for rich text
- Search across all your notes instantly

### Useful Commands
- `Ctrl/Cmd + P`: Open command palette
- `Ctrl/Cmd + O`: Quick switcher to open notes
- `Ctrl/Cmd + N`: Create a new note
- `Ctrl/Cmd + F`: Search in current note

## Next Steps
1. Create your first note in the [[Notes]] folder
2. Explore the different panes and features
3. Customize your vault settings in Settings → Appearance/Editor
4. Check out the graph view to see connections between your notes

Happy note-taking! 📝
